# Bellroy card component

A product card component built for [Astro](//astro.build) with [Elm](//elm-lang.org).
Take-home exercise for the frontend developer position at [Bellroy](//bellroy.com)

To run the example, clone the repository, and then run `yarn` followed by `yarn dev`
